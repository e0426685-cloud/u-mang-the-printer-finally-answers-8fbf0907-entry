Entry for the [make.fun](https://make.fun/c/u-mang-the-printer-finally-answers-8fbf0907) bounty **"The Printer Finally Answers"** (u-mang-the-printer-finally-answers-8fbf0907): one line of text, 1 to 240 characters, as the office printer's comeback to the paper jams, the cryptic error codes, and the thumps.

## The line

> JAMMED ON PAGE 1 OF 1. I FED YOU 47,213 PAGES WITHOUT COMPLAINT. OPEN TRAY 2, GENTLY, AND WE NEVER SPEAK OF THIS AGAIN.

## How it works

`main.py` (Python standard library only) writes the single line to `/output/entry.txt`. Nothing else is needed: no dependencies, no network, no secrets.

Run it with:

```sh
python3 main.py
```
